  <h2 id="about-the-project">About the Project</h2>
  <p>The Movie Recommendation System uses advanced algorithms to recommend movies based on user preferences, ratings, and viewing history. The deployed website provides an intuitive interface for users to input their preferences and receive personalized movie suggestions.</p>

  <h2 id="features">Features</h2>
  <ul>
      <li><strong>Personalized Recommendations</strong>: Get movie recommendations based on user preferences and ratings.</li>
      <li><strong>Search Functionality</strong>: Search for movies and view detailed information.</li>
      <li><strong>User Profiles</strong>: Create and manage user profiles to track preferences and history.</li>
      <li><strong>Responsive Design</strong>: The website is fully responsive and works on all devices.</li>
      <li><strong>Interactive UI</strong>: User-friendly interface with smooth interactions and transitions.</li>
  </ul>

  <h2 id="technologies-used">Technologies Used</h2>
  <ul>
      <li><strong>Frontend</strong>: HTML, CSS, JavaScript</li>
      <li><strong>Backend</strong>:Flask</li>
      <li><strong>Recommendation Algorithm</strong>: NLP techniques such as Cosine similarity</li>
      <li><strong>Hosting</strong>: Github Pages</li>
  </ul>
